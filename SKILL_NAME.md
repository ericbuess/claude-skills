# Skill Name Decision

## Final Name: `theological-explorer`

### Rationale

**Considered alternatives**:
- `truth-seeker` - Too generic, doesn't specify domain
- `worldview-navigator` - Good but less clear
- `faith-and-reason` - Too binary, implies conflict
- `belief-explorer` - Close but "belief" narrower than "theology"
- `epistemic-companion` - Too academic/jargon
- `theoria` - Obscure Greek, accessibility issue

**Why `theological-explorer`**:
- ✅ Clear domain: Theological questions
- ✅ Activity: Exploring (not defending, not attacking)
- ✅ Accessible: Plain English
- ✅ Accurate: Describes exactly what it does
- ✅ Neutral: Doesn't presuppose conclusions
- ✅ Inviting: "Explorer" is curiosity-driven

### Description (for YAML frontmatter)

```yaml
description: Socratic companion for exploring theological and philosophical questions through rigorous reasoning. Uses Bayesian probability, multi-agent debate, evidence grading, and adversarial validation. Adapts depth dynamically (brief/standard/deep). Celebrates questioning and intellectual virtues. Steel-mans all positions. Honors mystery and uncertainty. Trigger with questions about God, meaning, consciousness, suffering, worldviews, faith and reason. Integrates Eric's sandbox hypothesis as one framework (40-60% confidence) alongside classical theism, multiverse, naturalism.
```

**Trigger phrases**:
- "explore [theological question]"
- Questions about God, meaning, suffering, consciousness
- "What's the evidence for/against..."
- "How should I think about..."
- "Bayesian analysis of..."
- Request for "deep dive" or "comprehensive analysis"
